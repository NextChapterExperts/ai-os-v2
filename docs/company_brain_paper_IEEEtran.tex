\section{Why Current Agents Fail at Enterprise Systems}
\label{sec:intro}

\IEEEPARstart{W}{hen} developers hook Large Language Models (LLMs) to enterprise software, they hit a fundamental barrier. LLMs guess statistically plausible next tokens ($P(t_{i+1} \mid t_{1..i})$). When missing facts, they don't crash—they invent convincing stories.

Conversely, ERP engines like SAP operate deterministically. Financial records, travel rules, and price sheets require binary precision. We call this clash the \emph{Epistemological Asymmetry Problem}.

Granting probabilistic agents raw database access leads to three major breakdowns:
\begin{enumerate}
    \item \textbf{Context Drift:} Unverified chat notes leak into persistent graphs. Three weeks later, the agent hallucinates over its own past guesses.
    \item \textbf{Silent Failures:} An agent crafts a valid API payload that violates business rules (e.g., booking marketing spend onto R\&D accounts). The API call succeeds, but corrupts business analytics.
    \item \textbf{Token Explosions via Blind Retrieval:} Standard RAG setups query vector indexes, chat logs, and databases all at once for every prompt. This burns tokens, spikes latency, and feeds conflicting context into the window.
\end{enumerate}

We built the \emph{Company Brain} reference architecture in AI-OS v2 to eliminate these flaws. Our core principle is \emph{Cognitive-Executive Separation} (CES): the LLM handles intent extraction in the Cognitive Layer, while a deterministic Executive Kernel enforces validation gates and atomic commits.

\subsection{Our Contributions}
Our key contributions are:
\begin{itemize}
    \item \textbf{Three Epistemological Axioms:} Rules that block LLMs from directly mutating canonical corporate state.
    \item \textbf{Technology-Agnostic Five-State Memory Taxonomy:} Segregating ephemeral scratchpads from ground truth across five states ($\mathcal{S}_1..\mathcal{S}_5$).
    \item \textbf{Deterministic Query Router:} A code-driven router that targets memory layers in under 2ms without LLM calls in the hot path.
    \item \textbf{Empirical Evaluation:} Benchmarks on AI-OS v2 verifying 100\% schema compliance and zero cross-layer leaks.
\end{itemize}

Existing research falls into three main camps (Table~\ref{tab:comparison}).

\subsection{Virtual Memory Paging (MemGPT)}
Packer et al.~\cite{packer2023memgpt} introduced MemGPT, treating context as RAM and vector databases as disk. MemGPT relies on LLM function calls to edit memory. In our benchmarks, letting a probabilistic LLM manage its own memory caused \emph{memory drift}: agents overwrite real ground truth with past hallucinations.

\subsection{Hierarchical Cognitive Runtimes (AIOS)}
Mei et al.~\cite{mei2024aios} built the AIOS kernel for CPU/GPU scheduling. Subsequent systems split memory into working, episodic, and semantic layers. However, agents retain direct write access across all layers. They lack an enforcement firewall between ephemeral notes and binding corporate truth.

\subsection{Temporal Graphs (Graphiti)}
Graphiti~\cite{zep2025graphiti} uses temporal knowledge graphs for agent memory. Yet without deterministic query routing, systems still query all layers indiscriminately.

\section{Our Formal Memory Model}
\label{sec:model}

We formalize Company Brain through three core axioms and a five-state memory taxonomy.

\subsection{Core Axioms}

\subsubsection{Axiom I: Write Ban for LLMs}
\begin{equation}
\forall a \in \mathcal{A}, \quad \text{Mutate}(a, \mathcal{S}_{\text{canonical}}) = \bot
\end{equation}
An LLM agent $a \in \mathcal{A}$ cannot directly mutate the canonical state $\mathcal{S}_{\text{canonical}}$. Agents propose intents; the kernel validates and commits.

\emph{Example:} An agent reads a customer email claiming a 15\% verbal discount. Under Axiom~I, the agent cannot update the price database. It generates a draft proposal. Official prices remain untouched until ratified.

\subsubsection{Axiom II: Disjoint Memory Spaces}
\begin{equation}
\mathcal{S}_{\text{episodic}} \cap \mathcal{S}_{\text{canonical}} = \emptyset
\end{equation}
Chat history ($\mathcal{S}_{\text{episodic}}$) and ground truth ($\mathcal{S}_{\text{canonical}}$) stay in completely separate spaces.

\emph{Example:} A user chats: \emph{"Let's move syncs to Tuesdays."} The agent logs this in $\mathcal{S}_{\text{episodic}}$. The official project charter in $\mathcal{S}_{\text{canonical}}$ stays unchanged until approved.

\subsubsection{Axiom III: Deterministic Transition Guarding}
State transitions from $\mathcal{S}_{\text{episodic}}$ to $\mathcal{S}_{\text{canonical}}$ must pass a validation function $\mathcal{V}(p)$ for typed DataProduct $p$.

\subsection{Taxonomy of Five Memory States}

We define the complete state space as:
\begin{equation}
\mathcal{M} = \langle \mathcal{S}_{\text{transient}}, \mathcal{S}_{\text{episodic}}, \mathcal{S}_{\text{canonical}}, \mathcal{S}_{\text{procedural}}, \mathcal{S}_{\text{audit}} \rangle
\end{equation}

\begin{enumerate}
    \item \textbf{State 1: $\mathcal{S}_{\text{transient}}$ (Transient Operational State):} Working memory active during a single task run. Scratchpad tool outputs. Authority: $0\%$. Lifespan: $1$ execution.
    \item \textbf{State 2: $\mathcal{S}_{\text{episodic}}$ (Episodic Conversation State):} Interaction history, user preferences, and non-binding dialogue. Authority: Low. Lifespan: Session.
    \item \textbf{State 3: $\mathcal{S}_{\text{canonical}}$ (Canonical Ground Truth State):} Single source of truth ($\text{SSOT}$): ratified policies, active contracts, and official price sheets. Authority: $100\%$. Lifespan: Permanent/Versioned.
    \item \textbf{State 4: $\mathcal{S}_{\text{procedural}}$ (Procedural Capability State):} Reusable workflows and distilled skills ("How to process foreign invoices"). Authority: High. Lifespan: Versioned.
    \item \textbf{State 5: $\mathcal{S}_{\text{audit}}$ (Immutable Audit Ledger State):} Append-only, tamper-proof log of all tool calls and state commits. Authority: Absolute Proof. Lifespan: Indefinite.
\end{enumerate}

\section{Lifecycle Dynamics}
\label{sec:lifecycle}

Information moves between states via four transitions.

\subsection{Transition 1: Task to Episode ($\mathcal{S}_{\text{transient}} \rightarrow \mathcal{S}_{\text{episodic}}$)}
When a task finishes, the kernel compresses the scratchpad $\mathcal{S}_{\text{transient}}$ into a structured episodic summary in $\mathcal{S}_{\text{episodic}}$.

\subsection{Transition 2: Epistemic Distillation ($\mathcal{S}_{\text{episodic}} \rightarrow \mathcal{S}_{\text{canonical}}$)}
Unverified chat notes move into ground truth through a periodic curation cycle. A claim $c$ must pass three checks:
\begin{enumerate}
    \item \textbf{Confidence:} $\text{Conf}(c) \ge 0.70$.
    \item \textbf{Deduplication:} Cosine similarity $\text{Sim}(c, c') < 0.95$ against existing claims $c' \in \mathcal{S}_{\text{canonical}}$.
    \item \textbf{Human-in-the-Loop Gate:} Pricing or contract edits send an approval task to a manager's dashboard.
\end{enumerate}

\section{Deterministic Query Routing Protocol}
\label{sec:routing}

We avoid burning tokens on memory selection. Our router uses a zero-LLM classification function $\mathcal{R}(\text{Intent}) \rightarrow 2^{\mathcal{M}}$:

\begin{algorithm}[h]
\caption{Deterministic Query Routing Protocol}
\label{alg:router}
\begin{algorithmic}[1]
\REQUIRE Query string $Q$, Tenant ID $T$
\ENSURE Search Plan $\mathcal{P} \subseteq \{\mathcal{S}_{\text{canonical}}, \mathcal{S}_{\text{episodic}}, \mathcal{S}_{\text{procedural}}, \mathcal{S}_{\text{audit}}\}$
\STATE $\mathcal{P} \leftarrow \emptyset$
\IF{$Q$ contains keywords $\{\text{policy, rule, decision, contract, rate}\}$}
    \STATE $\mathcal{P} \leftarrow \mathcal{P} \cup \{\mathcal{S}_{\text{canonical}}\}$
\ELSIF{$Q$ contains keywords $\{\text{yesterday, last week, discussed, chat}\}$}
    \STATE $\mathcal{P} \leftarrow \mathcal{P} \cup \{\mathcal{S}_{\text{episodic}}\}$
\ELSIF{$Q$ contains keywords $\{\text{how-to, procedure, workflow, skill}\}$}
    \STATE $\mathcal{P} \leftarrow \mathcal{P} \cup \{\mathcal{S}_{\text{procedural}}, \mathcal{S}_{\text{canonical}}\}$
\ELSE
    \STATE $\mathcal{P} \leftarrow \{\mathcal{S}_{\text{canonical}}, \mathcal{S}_{\text{procedural}}\}$ \COMMENT{Default Safe Plan}
\ENDIF
\RETURN $\mathcal{P}$
\end{algorithmic}
\end{algorithm}

\emph{Example Query:} "What is the maximum allowed hotel expense in New York?" Algorithm~\ref{alg:router} routes this query strictly to $\mathcal{S}_{\text{canonical}}$ (Travel Policy). It excludes $\mathcal{S}_{\text{episodic}}$, preventing informal chat remarks from polluting results.

\section{Conclusion}
\label{sec:conclusion}

The Company Brain architecture solves the Epistemological Asymmetry Problem. By enforcing Cognitive-Executive Separation, isolating memory into five distinct states ($\mathcal{S}_1..\mathcal{S}_5$), and routing queries through a deterministic classification layer, AI-OS v2 eliminates memory drift, protects corporate ground truth, and guarantees cryptographic auditability.
